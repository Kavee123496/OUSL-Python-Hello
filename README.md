# OUSL Python Hello Assignment

## Purpose of this Repository
This repository is created as part of an assignment for the Open University of Sri Lanka (OUSL).  
It demonstrates a basic Python program to help beginners understand how to write and run Python scripts.

## About the Python Script
The script `hello.py` is a simple Python program that prints a greeting message to the screen.  
It helps students learn:
- How to create a Python file
- How to write Python code
- How to run Python scripts
